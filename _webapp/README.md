# agent学习平台

一个**本地网页版资料浏览器**：点击左侧目录即可在网页里直接阅读 Markdown、Jupyter Notebook、
代码、PDF，公式会渲染成真正的数学排版。

只在本机运行，不联网、不对外暴露。

---

## 一、启动

**双击 `start.bat`** 即可。

脚本会自动：
1. 查找 Python（`py` / `python` / `python3` 依次尝试）
2. 启动本地服务（默认端口 8777，被占用会自动顺延）
3. 打开浏览器

**停止**：关掉那个黑色命令行窗口，或在窗口里按 `Ctrl+C`。

> ⚠️ 服务运行期间不要关闭黑窗口，否则网页会打不开。

## 三、功能

### 首页 = 学习路线图

打开就是完整的学习路线，和独立的 `学习路线.html` 内容一致，但**与文件树打通**：

| 区块 | 交互 |
|---|---|
| **四阶段主线** | 时间轴展示 4 个阶段；每阶段底部有版块标签，**点击直接展开左侧对应目录** |
| **八个版块速查** | 每张卡显示**真实已读进度条**；点击卡片展开该版块目录 |
| **Agent 专项路径** | 6 步递进；每步的目录标签可展开，带 ▶ 的标签**直接打开对应 notebook** |
| **环境搭建** | 代码块可直接选中复制 |
| **配套教材与论文** | 两个按钮跳转到 IDM 清单和使用说明；另附 3 个在线书籍外链 |

> 进度来自你的实际阅读记录，读过文件后回到首页，进度条会自动更新。

### 左侧目录树
- 点击文件夹展开，**懒加载**（不会一次性读取 8000 个文件）
- 顶部输入框可按文件名**实时过滤**
- 已读文件右侧显示 `✓`
- `⊟` 按钮一键全部收起

### 三个面板
| 标签 | 内容 |
|---|---|
| **目录** | 文件树 |
| **最近** | 最近浏览的 60 个文件（本机保存） |
| **进度** | 各版块的已读文件数与进度条 |

### 全文搜索（`Ctrl+K` 或 `/`）
搜索所有 Markdown / 代码 / Notebook 的**文件内容**，返回：
- 命中的文件名 + 命中次数
- 命中行号 + 上下文（最多 4 行）
- 关键词黄色高亮

实测：搜 `transformer` 命中 8 个文件 / 158 处，耗时 1.7 秒。

### 右侧目录（TOC）
Markdown 的 `#`~`####` 标题自动生成目录，滚动时**高亮当前小节**，点击平滑跳转。

### 已读标记
- 打开文件 **30 秒后自动标记已读**
- 也可点标题栏的 `⬜` 按钮手动切换
- 进度保存在浏览器本地

### 其他
- **暗色模式**：点右上角 🌓，跟随系统偏好
- **图片放大**：点击任意图片
- **复制路径**：标题栏 📋 按钮，或点降级提示里的路径
- **站内链接**：Markdown 里的相对链接（如 `[见](./other.md)`）可直接点击跳转

## 六、桌面快捷方式

桌面上已有 **「agent学习平台」** 快捷方式（图标是吉祥物「大肥鱼」），双击即可启动。

| 属性 | 值 |
|---|---|
| 目标 | `C:\agent学习平台\_webapp\start.bat` |
| 起始位置 | `C:\agent学习平台\_webapp` |
| 图标 | `C:\agent学习平台\_webapp\assets\mascot.ico` |
| 窗口 | **最小化**（黑窗口会缩到任务栏，不挡视线） |

**停止服务**：点任务栏上那个最小化的窗口，按 `Ctrl+C` 或直接关掉它。

**想重建快捷方式**（比如换了路径或图标）：重新执行下面这段即可 ——

```powershell
$sh = New-Object -ComObject WScript.Shell
$s  = $sh.CreateShortcut("$([Environment]::GetFolderPath('Desktop'))\agent学习平台.lnk")
$s.TargetPath       = 'C:\agent学习平台\_webapp\start.bat'
$s.WorkingDirectory = 'C:\agent学习平台\_webapp'
$s.IconLocation     = 'C:\agent学习平台\_webapp\assets\mascot.ico,0'
$s.Description      = 'agent学习平台 —— 前沿 AI 从入门到精通'
$s.WindowStyle      = 7
$s.Save()
```

**想换图标**：把新图替换 `assets\mascot-source.jpg`，然后运行
`python assets\make-icons.py` 重新生成全套图标（会自动裁掉底部水印并生成 7 档尺寸）。
右键快捷方式 → 属性 → 更改图标，重新选一次即可刷新缓存。

## 七、常见问题

**Q: 端口 8777 被占用怎么办？**
A: 不用管，服务会自动往后找可用端口（尝试 20 个），命令行窗口会打印实际地址。

**Q: 公式显示成乱码 / 没渲染？**
A: 检查 `static\vendor\fonts\` 下是否有 60 个字体文件。KaTeX 需要这些字体文件。
若缺失，在 `_build` 目录重新执行 `npm install` 后复制 `node_modules\katex\dist\fonts\`。

**Q: Notebook 打开很慢？**
A: 部分 Notebook 内嵌大量 base64 图片（最大的 12 MB）。首次加载需要解析 JSON，
稍等几秒即可，之后浏览器会缓存。

**Q: 能在外网访问吗？**
A: 不能，也不建议。服务只监听 `127.0.0.1`，且所有路径都被限制在 `C:\agent学习平台` 内。

**Q: 进度数据存在哪？能导出吗？**
A: 存在浏览器的 `localStorage`（键名 `studyai.read`）。
换浏览器或清理浏览器数据会丢失。可在浏览器控制台用
`localStorage.getItem('studyai.read')` 查看。

**Q: 想改资料根目录？**
A: 编辑 `server.py` 顶部的 `ROOT = Path(r"C:\agent学习平台")`，改成你的路径即可。

## 八、技术说明

### 为什么需要本地服务器？

浏览器出于安全限制，`file://` 页面**无法**用 `fetch()` 读取本地其他文件，
也无法跨文件请求。所以必须由本地服务提供文件内容。

### 安全措施

| 措施 | 说明 |
|---|---|
| 仅监听回环地址 | `127.0.0.1`，外部无法访问 |
| 路径白名单 | 所有请求经 `realpath` 解析后必须落在 `C:\agent学习平台` 内 |
| 目录穿越防护 | `../../Windows/win.ini` 等 3 种变体实测均返回 **403** |
| Notebook 输出净化 | 剥离 `<script>`、`on*` 事件属性，防注入 |
| 大文件拦截 | 文本 >8 MB 不读，二进制 >64 MB 不传 |
| 敏感目录隐藏 | `.git` `node_modules` `__pycache__` 等不出现在树里 |

### 公式渲染的关键处理

Markdown 里的 `$a_b$` 会被解析成斜体、`$$...\\...$$` 的反斜杠会被转义，
所以**必须在 Markdown 解析前把公式抽出来占位**，解析完再回填 KaTeX：

```
原文 → ① 抽出代码块(占位) → ② 抽出公式(占位) → marked 解析
     → ③ 回填代码块 → ④ 回填 KaTeX 公式 → ⑤ 重写图片/链接路径
```

占位符用 Unicode 私有区字符（`\uE000`/`\uE001`），Markdown 不会碰它们。

### 性能

| 项 | 实测 |
|---|---|
| 目录树加载 | 懒加载，根目录 ~40 ms |
| 统计接口 | 首次 1.46 s，**缓存后 0.040 s**（10 分钟有效） |
| 全文搜索 | 25 MB 文本，1.73 s |
| 公式渲染 | 单文件 215 个公式块，~1 s |
