核心功能

看不懂？
划一下就行。

选中一段文字，点「问大肥鱼」，旁边立刻冒出一个小气泡开始写答案。 眼睛不用离开那一行。

  • 不用切软件、不用复制粘贴
  • 答案一个个字蹦出来，不是等半天
  • 气泡能用鼠标拖着走，对照原文看
  • 它知道你在读第几章第几节
划词 → 就地出答案
数学教材

它真的会排版数学。

公式不是图片，也不是纯文本，是真正的 LaTeX 排版。 定理、定义、证明会渲染成彩色框，跟导出的 PDF 长得一样。

  • 行内公式 $V$ 这种单字母也正常
  • 块级公式居中、带编号、能横向滑动
  • 定义绿 / 定理蓝 / 例题琥珀 / 证明虚线
  • 自动生成右侧本页目录

手机端

躺着读，不算堕落。

手机上不是「缩小版」，是独立的一套单栏界面：目录收进抽屉，陪读收进一颗悬浮球。

首页 → 开始学习 → 划词提问，手机上一条路走到底

有多轻

轻得不像个「平台」。

因为它压根不是平台。它是个软件。

7,000+行代码含双端 + 两套资源
0个 npm 依赖没有构建步骤
1条命令启动python server.py
¥0使用成本没有订阅，没有广告

没有账号系统，因为没有「别人」。
没有数据库，因为进度就存在你浏览器里。
没有服务器，因为数据从来不出这台电脑。

说句公道话

它不适合所有人。

先看看自己是不是这种需求。

你在意的 大肥鱼阅读器 一般阅读软件
要登录吗不要，打开就用先注册，再验证手机号
资料存在哪你自己的硬盘他们的云（要收存储费）
能不能导出文件本来就是文件「该功能需会员」
有没有广告没有。我靠什么赚钱？不赚开屏 + 信息流推荐
换设备同步不支持（自己放网盘）支持（数据在云端）
多端协同编辑没有有
移动端 App网页版（加到主屏幕）有原生 App

后面三条是真的没有。我不打算做，因为做了就要有服务器，有服务器就会有第二个「要钱」的理由。

它不是产品，是我自己的读书工具。
不过你可以直接拿走用。
