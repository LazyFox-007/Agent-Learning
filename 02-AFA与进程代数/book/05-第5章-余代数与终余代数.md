# 第 5 章　余代数与终余代数

> **本章导读**　前三章把“图—装饰—互模拟”讲成了一个完整的故事。本章换一套语言重讲一遍：图是余代数，装饰是余代数同态，AFA 是终余代数的存在性。换语言不是故弄玄虚——只有站到这个高度，才能看清“进程即超集合”不是巧合，而是终性的必然。

## 学习目标

- 理解函子、余代数、余代数同态的定义；
- 会用 $F(X)=A\times X$、$\wp_f$、$\wp(L\times -)$ 三个例子翻译流、图与迁移系统；
- 证明 $(V_A,\mathrm{id})$ 是幂集函子的终余代数；
- 用“关系提升”把互模拟写成余代数之间的 span；
- 说明为什么 ZFC 里没有终余代数，而 AFA 恰好补上这一块；
- 画出“语法—行为”的语义三角。

## 5.1 从图到函子

第 3 章的图是 $G=(V,E)$，$E \subseteq V\times V$。换个写法：每个节点 $v$ 对应它的孩子集 $vE \subseteq V$。于是图就是一个函数

$$ \xi: V \to \wp(V),\qquad \xi(v)=vE. $$

这正是“余代数”的雏形：一个状态集 $V$，加上一个把状态送到“一步之后的状态集合”的函数。不同的系统有不同的“一步之后”的形状：流的一步之后是一个元素加一个后继，迁移系统的一步之后是一族“动作 + 后继”。把这些形状抽象出来，就是函子。

::: definition 5.1（函子）
设 $\mathbf{Set}$ 是集合与函数的范畴（或 $\mathbf{Class}$ 是类与类函数的范畴）。一个**函子** $F:\mathbf{Set}\to\mathbf{Set}$ 由两部分组成：

- 对每个集合 $X$，指定一个集合 $F(X)$；
- 对每个函数 $f:X\to Y$，指定一个函数 $F(f):F(X)\to F(Y)$；

并满足 $F(\mathrm{id}_X)=\mathrm{id}_{F(X)}$，$F(g\circ f)=F(g)\circ F(f)$。
:::

本书用到的函子有：

| 函子 | $F(X)$ | 直观 |
| --- | --- | --- |
| $A\times -$ | $A\times X$ | 一个 $A$ 元素 + 一个后继 |
| $1+-$ | $1\sqcup X$ | 停止，或继续 |
| $\wp$ | $\wp(X)$ | 任意多个后继 |
| $\wp_f$ | $\wp_f(X)$ | 有限多个后继 |
| $\wp(L\times -)$ | $\wp(L\times X)$ | 带标签的多个后继 |

其中 $A\times -$ 把 $f:X\to Y$ 送到 $\mathrm{id}_A\times f$；$\wp$ 把 $f$ 送到 $S\mapsto f[S]$；$\wp(L\times -)$ 把 $f$ 送到 $S\mapsto\{(\ell,f(x))\mid(\ell,x)\in S\}$。

## 5.2 余代数与同态

::: definition 5.2（余代数）
函子 $F$ 的一个**余代数**是序对 $(X,\xi)$，其中 $X$ 是集合（或类），$\xi:X\to F(X)$ 是函数。$X$ 称为**状态集**，$\xi$ 称为**结构映射**或**观察函数**。

设 $(X,\xi)$、$(Y,\theta)$ 是 $F$-余代数。函数 $f:X\to Y$ 是**余代数同态**，如果

$$ \theta\circ f = F(f)\circ \xi. \qquad (5.1) $$
:::

用交换图说，就是“先观察再映射”与“先映射再观察”两条路给出同一个结果：

![图 5-1　余代数同态的交换图](figures/fig-commute.png)

式 (5.1) 说：先观察再映射，等于先映射再观察。这是“同态”一词在余代数世界的版本。

::: example 例 5.3（流）
$F(X)=A\times X$。余代数 $(X,\xi)$ 的结构映射形如 $\xi(x)=(\mathrm{head}(x),\mathrm{tail}(x))$。同态 $f:(X,\xi)\to(Y,\theta)$ 满足

$$ \mathrm{head}(f(x))=\mathrm{head}(x),\qquad \mathrm{tail}(f(x))=f(\mathrm{tail}(x)). $$

也就是说，$f$ 保持头与尾。
:::

::: example 例 5.4（图）
$F=\wp$。余代数 $(X,\xi)$ 就是图：节点 $x$，孩子集 $\xi(x)$。同态 $f:(X,\xi)\to(Y,\theta)$ 满足

$$ \theta(f(x))=\{f(y)\mid y\in\xi(x)\}. \qquad (5.3) $$

第 3 章的“装饰”就是同态：装饰 $d:G\to(V_A,\mathrm{id})$ 满足 $d(x)=\{d(y)\mid y\in\xi(x)\}$。
:::

::: example 例 5.5（迁移系统）
$F=\wp(L\times -)$。余代数 $(S,\xi)$ 的 $\xi(s)\subseteq L\times S$ 就是迁移关系：$(\ell,s')\in\xi(s)$ 当且仅当 $s\xrightarrow{\ell}s'$。
:::

## 5.3 终余代数

::: definition 5.6（终余代数）
$F$-余代数 $(C,\gamma)$ 是**终的**（final），如果对每个 $F$-余代数 $(X,\xi)$，都存在唯一的同态 $h:(X,\xi)\to(C,\gamma)$。
:::

终对象在范畴论中是“万有吸引子”：所有对象都唯一地指向它。对余代数来说，这个“吸引子”就是把每个状态送到它的行为。

::: theorem 5.7（幂集函子的终余代数）
在 ZFA + AFA 中，$(V_A,\mathrm{id})$ 是 $\wp$-函子的终余代数。这里 $\mathrm{id}:V_A\to\wp(V_A)$ 是恒等映射（注意 $\wp(V_A)=V_A$，因为 $V_A$ 是全集）。
:::

::: proof 证明
**同态存在。** 给定 $(X,\xi)$，构造图：节点集 $X$，边 $x\to y$ 当且仅当 $y\in\xi(x)$。由 AFA，它有唯一装饰 $d:X\to V_A$，满足

$$ d(x)=\{d(y)\mid y\in\xi(x)\}. $$

这正是同态条件：$\mathrm{id}(d(x))=\wp(d)(\xi(x))$，即 $d(x)=\{d(y)\mid y\in\xi(x)\}$。

**同态唯一。** 若 $k:X\to V_A$ 也是同态，则 $k(x)=\{k(y)\mid y\in\xi(x)\}$，即 $k$ 也是该图的装饰；由 AFA 装饰唯一，$k=d$。∎
:::

这个证明只有三行，却把第 2、3 章的全部内容收进了一个范畴论命题。值得记住它的形状：**终性 = 装饰的存在唯一性**。

::: corollary 5.8
对 $\wp$-余代数 $(X,\xi)$ 与 $x,y\in X$：$x\sim y$ 当且仅当 $h(x)=h(y)$，其中 $h$ 是唯一的终同态。
:::

这就是“互模拟 = 指称相等”的范畴论版本。第 3 章用图论证明过；这里用终性重新证明一遍。

## 5.4 互模拟作为 span

终性给出了“指称”，但互模拟本身还没有范畴论定义。用关系提升可以补上。

::: definition 5.9（关系提升）
设 $F=\wp$。对关系 $R\subseteq X\times Y$，定义

$$ F(R)=\Bigl\{(S,T)\in\wp(X)\times\wp(Y) \ \Bigm|\ \forall x\in S\,\exists y\in T\,(x,y)\in R,\ \text{且}\ \forall y\in T\,\exists x\in S\,(x,y)\in R\Bigr\}. \qquad (5.4) $$
:::

$F(R)$ 就是“按 $R$ 配对后彼此覆盖”的集合对。对带标签的函子 $\wp(L\times -)$，把 $\forall x\in S$ 换成 $\forall(\ell,x)\in S$，并要求标签相同即可。

::: proposition 5.10
$R\subseteq X\times Y$ 是余代数 $(X,\xi)$ 与 $(Y,\theta)$ 之间的互模拟，当且仅当存在函数 $\rho:R\to F(R)$，使得两个投影 $\pi_1:R\to X$、$\pi_2:R\to Y$ 都成为余代数同态：

![图 5-2　互模拟作为 span](figures/fig-span.png)
:::

换句话说，互模拟就是“在关系上也能定义余代数结构，使两个投影都是同态”。对 $\wp$ 展开 (5.5)，就得到 zig-zag 条件；对 $\wp(L\times -)$，就得到带标签的 zig-zag。

::: theorem 5.11
设 $(C,\gamma)$ 是终余代数，$h_X,h_Y$ 分别是 $X,Y$ 到 $C$ 的唯一同态。则对任意 $x\in X,y\in Y$：

$$ x\sim y \quad \Longleftrightarrow \quad h_X(x)=h_Y(y). \qquad (5.6) $$
:::

::: proof 证明
(⇒) 若 $R$ 是互模拟且 $(x,y)\in R$，由 (5.5) 与终性，$h_X\circ\pi_1$ 与 $h_Y\circ\pi_2$ 都是从 $R$ 到 $C$ 的同态，故相等；于是 $h_X(x)=h_Y(y)$。

(⇐) 若 $h_X(x)=h_Y(y)$，令 $R=\{(u,v)\mid h_X(u)=h_Y(v)\}$。由 $h_X,h_Y$ 是同态，$R$ 满足 (5.5)，故是互模拟。∎
:::

## 5.5 特殊终余代数定理

不是所有函子都有终余代数。Aczel 证明了一类“标准函子”有。

::: theorem 5.12（特殊终余代数定理，Aczel）
由常量函子、恒等函子、积、余积、幂集函子，以及它们与“小”指数函子的组合所构成的函子，都有终余代数。这类函子称为**标准函子**。
:::

本书需要的三个实例：

- $F=\wp$：终余代数是 $(V_A,\mathrm{id})$，如定理 5.7；
- $F=\wp(L\times -)$：终余代数是 $(V_A(L),\mathrm{id})$，其中 $V_A(L)$ 是满足 $V_A(L)=\wp(L\times V_A(L))$ 的最大类，也就是“元素都是序对 $(a,x)$”的标号超集合类；
- $F=A\times -$：终余代数是 $A^\omega$（在 ZFC 中已经存在，不需要 AFA）。

对 $\wp_f$ 要多说一句。$\wp_f$ 的终余代数也存在，它由“有限分支”的超集合组成；但本书不需要它的完整构造。我们只需要一个较弱的事实：

::: proposition 5.13
设 $(X,\xi)$ 是 $\wp_f$-余代数且 $X$ 有限。则它的终同态落在 $\mathrm{HF}_A$（遗传有限的超集合）中。
:::

::: proof 证明
装饰 $d(x)=\{d(y)\mid y\in\xi(x)\}$ 是有限集（因为 $\xi(x)$ 有限）。由于 $X$ 有限，从 $x$ 可达的节点只有有限多个，故 $\mathrm{tc}(d(x))$ 是有限多个有限集的并，仍有限。∎
:::

这个命题会在第 11 章用到：有限状态的 CCS 进程，指称是遗传有限的超集合。

## 5.6 为什么 ZFC 不够

现在回答一个自然的问题：既然终余代数这么好，为什么不在 ZFC 里直接用它？

::: theorem 5.14
在 ZFC 中，$\wp$-函子没有终余代数；$\wp_f$-函子也没有。
:::

::: proof 证明
反设 $(C,\gamma)$ 是 $\wp$ 的终余代数。考虑单点余代数：$X=\{s\}$，$\xi(s)=\{s\}$。设 $h:X\to C$ 是唯一同态，则

$$ \gamma(h(s))=\{h(s)\}, $$

即 $h(s)$ 是一个满足 $x=\{x\}$ 的集合。但 ZFC 中不存在这样的集合（命题 1.7），矛盾。

对 $\wp_f$ 同理：单点自环是 $\wp_f$-余代数，其同态像同样满足 $x=\{x\}$。∎
:::

这个证明说明：**ZFC 缺的不是技术，而是对象**。单点自环的“行为”就是 $\Omega$，而 ZFC 里没有 $\Omega$。AFA 的作用，正是把 $\Omega$ 及其同类请进论域，使终余代数有容身之处。

::: remark 注 5.15（“终语义”）
在进程代数文献中，把进程的指称定义为“到终余代数的唯一同态”，称为**终语义**（final semantics）。这个术语由 Aczel 与 Mendler 在 1980 年代末推广。终语义的优点是：

- 指称与操作语义无关，只依赖行为；
- 互模拟自动成为指称相等；
- 递归定义由终性保证有唯一解。

代价是：需要一个足够大的论域（ZFA + AFA），否则终对象不存在。
:::

## 5.7 初始代数与终余代数

最后，用一张图把“语法”与“行为”串起来。

设 $\Sigma$ 是进程代数的签名（$0$、$a.$、$+$、$|$、$\backslash L$、$[f]$、$\mathrm{rec}$）。项代数 $T_\Sigma$ 是 $\Sigma$-代数的初始对象：从它出发，到任何 $\Sigma$-代数都有唯一同态。另一方面，行为空间 $V_A(L)$ 是 $\wp(L\times -)$ 的终余代数：从任何迁移系统出发，到它都有唯一同态。

把两者放在一起，就得到第 11 章要证明的“语义三角”：

![图 5-3　语义三角：语法、商、行为](figures/fig-triangle.png)

其中 $q$ 是商映射（把语法项商去互模拟），$\llbracket\cdot\rrbracket$ 是指称。交换图说的是：**先商去互模拟，再取指称，等于直接取指称**。

::: remark 注 5.16（两条路）
从语法到行为，有两条路：

1. **操作路线**：先定义迁移系统，再取互模拟商，得到行为；
2. **指称路线**：直接把项解释为超集合，互模拟自动成为相等。

第 11 章会证明两条路给出同一个结果。这就是“进程即超集合”的精确含义。
:::

## 本章小结

- 函子把“一步之后的形状”抽象出来；余代数就是“状态 + 观察函数”。
- 余代数同态满足 $\theta\circ f=F(f)\circ\xi$；装饰就是到 $(V_A,\mathrm{id})$ 的同态。
- $(V_A,\mathrm{id})$ 是 $\wp$ 的终余代数；终性 = 装饰的存在唯一性。
- 互模拟可以用关系提升写成 span；终同态的核 = 互模拟。
- ZFC 中没有 $\wp$ 的终余代数；AFA 补上了 $\Omega$ 这类对象。
- 语法是初始代数，行为是终余代数，语义是两者之间的唯一映射。
