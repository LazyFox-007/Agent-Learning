## 六、技术备忘

### 缓存策略（改完文件看不到变化就是这个原因）

`/static/` 下的文件**文件名不带版本号**，所以不能长缓存：

| 路径 | 缓存策略 | 原因 |
|---|---|---|
| `/`、`/static/*.js`、`/static/*.css` | **no-store** | 文件名无哈希，长缓存会导致改完仍是旧版 |
| `/static/vendor/*` | 7 天 | 第三方固定版本库（marked / KaTeX / hljs），内容永不变 |
| 图片 / 字体 / 图标 | 7 天 | 同上 |
| `/files/*`（课程） | **no-store** | 重新导入课程后必须立刻生效 |
| `/api/raw` 文本 | **no-store** | 改了正文立刻可见 |
| `/api/raw` 图片 | 1 小时 | 避免每次翻页重新解码 |

> ⚠️ 早期版本给 `/static/` 统一设了 `max-age=86400`，结果**改完 roadmap.js 后浏览器 24 小时内还在用旧版**。
> 如果你看到页面内容和文件对不上，先按 `Ctrl`+`F5` 强制刷新。

### 平台为 HTML 多页站点加了 `/files/` 路由

原本 HTML 走 `/api/raw?path=...`，但浏览器解析相对链接时**只用路径部分、会丢弃 query**，
导致课程内的相对导航全部失效。新增 `/files/<相对路径>` 路由按真实目录结构提供文件后解决。

### HTML 用宽屏模式

平台正文默认 `max-width: 860px`（利于阅读纯文本），但会把课程 iframe 挤得很小。
渲染 HTML 时会给 `.doc` 加 `doc--wide` 类，脱离该限制、撑满内容区，
并让 iframe 用 flex 自动填满剩余高度。右上角另有一个 **↗** 按钮可在新标签页全屏打开。

### 目录穿越防护

`/files/` 路由同样经过 `realpath` 白名单校验，实测：

| 攻击向量 | 结果 |
|---|---|
| `/files/../../Windows/win.ini` | 404 拦截 |
| `/files/..%2F..%2FWindows%2Fwin.ini` | 403 拦截 |

### 一个前端坑：`display` 会盖掉 `[hidden]`

浮动按钮用 `hidden` 属性控制显隐，但 `.fab{display:flex}` 是**作者样式**，
优先级高于浏览器默认的 `[hidden]{display:none}` —— 结果两个按钮永远显示。

```css
.fab[hidden]{display:none}   /* 必须显式写 */
```

本项目里 `.side-pane`、`.tchildren`、`.search-overlay` 都有同样的补丁，
新增带 `hidden` 的元素时记得一并处理。

### `.bat` 必须是 CRLF 行尾 + 无 BOM

**症状**：双击 `start.bat` 窗口一闪而过，服务起不来。
**原因**：文件被改成了 **LF 行尾**，cmd.exe 无法正确解析多行 `if (...)` 括号块。

| 要求 | `.bat` / `.cmd` | `.ps1` |
|---|---|---|
| 行尾 | **必须 CRLF** | LF 也可以 |
| BOM | **必须无 BOM**（有 BOM 会让首行命令失效） | **必须有 BOM**（否则 PS 5.1 按 GBK 解析中文） |

**改完务必校验**：

```powershell
$b = [System.IO.File]::ReadAllBytes('C:\StudyAI\_webapp\start.bat')
$crlf = 0; $lf = 0
for ($i=0; $i -lt $b.Length; $i++) {
  if ($b[$i] -eq 0x0A) { if ($i -gt 0 -and $b[$i-1] -eq 0x0D) { $crlf++ } else { $lf++ } }
}
"CRLF=$crlf  裸LF=$lf  BOM=$(if($b[0] -eq 0xEF){'有'}else{'无'})"
# 期望：裸LF=0，BOM=无
```

`start.bat` 已改用 `goto` 标签而非多行括号块 —— 这种写法对行尾差异不敏感，
即使将来又被改成 LF 也仍能运行。

## 吉祥物与图标资产

形象是「大肥鱼」—— 一只戴圆眼镜、抱着书读的胖蓝鱼。

### 两张源图，各司其职

| 源图 | 用途 | 特点 |
|---|---|---|
| `fish_flat_v2` | **界面内图标**：顶栏、陪读头像、目录树 | 透明背景，融入任何底色 |
| `fish_app_v4` | **应用图标**：favicon、快捷方式、apple-touch | 带浅蓝圆角底，16px 仍清晰 |
| `fish_scene_v3` | 场景插图（备用） | 书桌、堆书、热茶，适合大幅展示 |

### 生成流程

```powershell
# 1) 一整套图标（会覆盖 assets/ 与 static/ 下的同名文件）
python C:\StudyAI\_webapp\_build\make-fish-icons.py <透明源图> <带底源图>

# 2) 只预览某个源图在各尺寸下的清晰度
python C:\StudyAI\_webapp\_build\preview-icon.py <源图路径>
```

产物：

```
_webapp/assets/
  mascot-fish.png        512 母版（透明）
  app-icon-256.png       带圆角底，用于快捷方式
  mascot.ico             多尺寸 ico（16~256），桌面快捷方式用
  reading-scene.png      场景插图
  _icon-preview.png      浅底/深底对照预览表

_webapp/static/
  mascot-512/256/64.png  界面用 PNG
  fish-32.png fish-22.png  目录树用的图标
  favicon.ico            浏览器标签
  apple-touch-icon.png   180px
```

### 白色背景转透明：必须用洪水填充

源图是白底。**不能全局去白** —— 鱼的肚皮、眼镜镜片的高光也是白的，
一刀切会把它们一起抠掉。

`make-fish-icons.py` 里用「从四条边洪水填充」（`remove_bg_flood`），
只有和画布边缘连通的白色才会被清除，内部的白色安全保留。

### 想换掉课程图标

改一个地方就行：

```js
// _webapp/static/app.js
var ICON_LESSON = '/static/fish-22.png';   // ← 换这里
```

图片放进 `_webapp/static/`，建议 22~32px 见方、透明背景。

### Windows 快捷方式图标不刷新？

Windows 有图标缓存。改完 `mascot.ico` 后，重新保存一次 `.lnk`
（脚本已自动做），必要时执行：

```powershell
ie4uinit.exe -show
```

还不行就等重启，或手动把 ico 换个文件名。
